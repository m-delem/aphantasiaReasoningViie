# Results of the contrast analyses performed on the `mgcv` non-linear models

These analyses were saved as package data to compensate for the fact
that the non-linear model fits themselves were too heavy to be saved in
the package. They are used to display the statistics in the
`vignette("nl_modelling")`.

## Usage

``` r
nl_contrasts
```

## Format

An object of class `list` of length 3.
